Tracking SA는 NEXON Open API 기반 서든어택 공개 전적과 SOOP 공식 API 기반 라이브 방송 정보를 한곳에서 제공하는 게임 데이터 서비스입니다.

전적 검색, 최근 기록 분석, 라이브 방송 시청과 크루 리그 운영 기능을 목적에 따라 분리해 빠르게 이용할 수 있도록 구성합니다.

운영 주체: Tracking SA Team

연락처: demo-15b9ce4f@example.com

서비스 구성

  • NEXON Open API 기반 프로필과 폭파미션 매치 유형별 최근 최대 20경기를 제공합니다.
  • 최근·이전 20경기 변화, 최근 31일 날짜별 활동, VS 비교와 즐겨찾기를 제공합니다.
  • SOOP 공식 API를 통해 현재 방송 중인 서든어택 라이브 정보를 제공합니다.
  • 리그 허브는 크루 랭킹, 신청, 팀 밸런서, 운영 기능을 별도 흐름으로 제공합니다.
  • 공지사항 페이지를 통해 구조 변경, 운영 일정, 주요 업데이트를 안내합니다.

편집 및 콘텐츠 원칙

  • 출처 기반 사실 요약과 관점 분석을 분리합니다.
  • 추정·의견은 명확히 구분하고 과장 표현을 지양합니다.
  • 법률·의료·투자 판단의 최종 책임은 사용자에게 있습니다.
