같은 50%라도 2경기와 20경기에서 한 경기가 차지하는 비중은 다릅니다. 분모를 확인하고, 비교를 보류할 상황을 구분하는 방법입니다.

계산 예시 안내

아래 계산 표는 원리를 설명하기 위한 가상 예시입니다. 실제 플레이어의 전적이나 새로 관측한 데이터가 아닙니다. 직접 기록하는 표는 별도 메모에 옮겨 사용하세요.

한 경기의 영향부터 계산합니다

승률은 승리 수 ÷ 실제 경기 수 × 100입니다. 경기 수 N을 고정한 채 1패가 1승으로 바뀌면 승률 차이는 100 ÷ N %p입니다. 아래는 분모가 늘어나는 계산이 아니라, 같은 크기의 구간에서 결과 한 개가 교체되는 예시입니다.

가상 예시 · 같은 경기 수에서 1패가 1승으로 바뀔 때
경기 수변경 전변경 후승률 차이
2경기1승 / 2경기 = 50%2승 / 2경기 = 100%+50%p
6경기3승 / 6경기 = 50%4승 / 6경기 ≈ 66.7%+16.7%p
20경기10승 / 20경기 = 50%11승 / 20경기 = 55%+5%p

작은 표본에서 큰 변화가 보이는 것은 오류의 증거가 아닙니다. 반대로 20경기가 됐다고 경기들이 동일한 조건에서 독립적으로 모였거나, 다음 경기의 승률을 예측할 수 있다는 뜻도 아닙니다.

화면의 경기 수와 안내 문구를 구분합니다

  1. ‘전체’에서 최근·이전 구간 각각의 실제 경기 수를 확인합니다. 이전 기록이 6경기라면 ‘이전 20경기’라는 이름으로 표시돼도 6경기 표본입니다.
  2. 경쟁 모드 최근 흐름 평가에서 ‘최신 구간’ 경기 수와 ‘비교 표본 부족’ 표시를 봅니다. 현재 구현은 최근 또는 이전 구간이 7경기 미만일 때 승률·킬뎃 차이 대신 비교 표본 부족을 표시합니다.
  3. 같은 평가에 표시된 최근·이전 구간의 실제 경기 수를 확인하세요. 경기 수는 통계적 신뢰수준이나 검정 결과를 뜻하지 않습니다.
  4. 맵별로 직접 나누거나 VS 상대와 비교할 때는 각 묶음의 분모를 다시 적습니다. 전체 20경기의 수를 특정 맵 2경기에 그대로 적용하면 안 됩니다.

이럴 때는 결론을 보류합니다

기록 해석용 · 숫자 옆에 분모와 다음 확인 항목을 남깁니다
관찰한 상황지금 말할 수 있는 내용다음에 확인할 것
한 맵 2전 2승조회된 두 경기에서 모두 승리그 맵의 새 경기 수와 맵 비중; 고정된 강점으로 단정하지 않기
최근 20경기, 이전 6경기최근 구간은 20경기, 이전은 6경기뿐이전 구간의 실제 분모와 비교 표본 부족 표시
VS에서 A 20경기, B 6경기서로 다른 분모에서 나온 비율동일 유형인지, 각자의 승리 수·킬·데스 합계가 얼마인지
최근과 이전 모두 20경기같은 개수의 두 구간을 비교 가능맵·유형 구성과 구간 겹침 여부; 경기 수만으로 원인 단정하지 않기

다음 조회에 쓸 메모를 남깁니다

조회 시각 / 매치 유형·구간 / 승리 수·전체 경기 수 / K/D / 맵별 경기 수 / 최신 경기 / 다음에 확인할 질문

예를 들어 ‘A맵이 강하다’ 대신 ‘최근 20경기 중 A맵 2경기, 2승. 다음 조회에서 A맵 새 경기가 추가됐는지 확인’이라고 적습니다. 비교할 표본이 없으면 변화량을 0으로 채우지 말고 ‘비교 불가’로 남깁니다.

K/D는 승률의 분모와 다릅니다. 경기별 킬뎃 퍼센트를 단순 평균하지 말고, 같은 구간의 킬·데스 합계를 사용하는 킬뎃 계산 안내를 확인하세요.

출처와 적용 범위

Tracking SA 공개 전적 화면의 매치 유형, 최근·이전 구간, 표시 경기 수와 매치 목록을 기준으로 정리했습니다. 데이터 누락·공개 API 반영 시차가 있을 수 있으며, 20경기라는 수나 화면의 표본 수 표시는 통계적 검증 또는 실력 판정을 보증하지 않습니다.
