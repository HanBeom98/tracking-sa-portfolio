Tracking SA 서비스 안내

Tracking SA는 서든어택 유저가 닉네임 검색부터 최근·이전 20경기 비교, 최근 31일 활동, VS 비교, 라이브 방송과 리그 허브까지 한 흐름으로 이용할 수 있도록 구성한 정보 서비스입니다.

이 사이트가 해결하려는 문제

서든어택 전적을 확인하려는 사용자는 보통 닉네임 검색 이후에 최근 경기 흐름, 시즌 누적 지표, 특정 상대와의 비교, 리그 참여 판단까지 연속적으로 확인하게 됩니다. Tracking SA는 이 과정을 흩어진 메뉴가 아니라 하나의 사용 흐름으로 정리하는 데 목적이 있습니다. 처음 방문한 사용자도 핵심 경로를 바로 찾을 수 있고, 자주 방문하는 사용자는 반복 행동을 빠르게 끝낼 수 있어야 한다는 기준으로 구조를 다듬고 있습니다.

전적 검색과 설명형 콘텐츠를 함께 두는 이유

전적 서비스는 수치가 많아질수록 초보 사용자가 해석을 어려워합니다. 승률이나 K/D 같은 숫자만 보여 주면 표본이 적은 최근 경기, 맵 편차, 시즌 누적 흐름 같은 맥락을 놓치기 쉽습니다. 그래서 Tracking SA는 검색 기능만 제공하지 않고, 가이드 허브를 통해 숫자를 읽는 기준과 실제 사용 순서를 별도의 문서로 설명합니다.

  • 검색 페이지는 빠른 확인을 돕습니다.
  • 가이드 페이지는 숫자의 의미를 풀어 설명합니다.
  • 서비스 소개와 정책 페이지는 운영 주체와 책임 범위를 명확히 합니다.

리그 허브를 별도로 분리한 이유

공개 전적 검색 사용자의 목적과 리그 운영 사용자의 목적은 다릅니다. 전적 검색 사용자는 가볍고 빠른 탐색을 원하지만, 리그 참여자는 공지 확인, 멤버 검색, 신청 흐름 같은 운영성 기능을 반복해서 사용합니다. Tracking SA는 두 목적을 한 화면에 섞지 않고 분리해 검색 경험을 단순하게 유지하고, 리그 허브에서는 운영 흐름을 또렷하게 보여 주도록 설계했습니다.

운영과 신뢰를 위해 공개하는 정보

홈과 푸터에는 서비스 소개, 문의, 개인정보처리방침, 이용약관, 사이트맵을 상시 연결합니다. 운영 주체와 연락 수단, 데이터 처리 방식을 사용자가 바로 확인할 수 있도록 하기 위해서입니다. 주요 가이드는 홈과 가이드 허브, 전적 허브에서 서로 연결해 검색 결과를 이해하는 데 필요한 설명을 쉽게 찾을 수 있게 합니다.

  1. 서비스 목적을 홈에서 먼저 설명합니다.
  2. 운영 주체와 문의 수단을 고정적으로 노출합니다.
  3. 정책 페이지와 가이드 문서를 내부 링크로 묶습니다.
  4. 업데이트 흔적은 홈의 최근 업데이트 섹션과 공지로 보강합니다.

처음 방문한 사용자에게 권장하는 순서

처음 사용하는 경우 전적 검색 홈에서 닉네임으로 공개 전적을 확인하고, 최근 경기 해석법과 20경기 비교 가이드를 읽은 뒤 필요하면 VS 비교나 리그 허브로 이동하면 됩니다.
