계산 예시 안내

아래 계산 표는 원리를 설명하기 위한 가상 예시입니다. 실제 플레이어의 전적이나 새로 관측한 데이터가 아닙니다. 직접 기록하는 표는 별도 메모에 옮겨 사용하세요.

화면에서 비교 조건부터 맞춥니다

  1. 같은 플레이어인지 확인한 뒤 동일한 매치 유형을 선택합니다. 위장 닉네임처럼 이름이 바뀐 경우에는 이름만 보고 서로 다른 사람의 기록을 비교하지 마세요.
  2. ‘전체’에서는 ‘최근 20경기’ 또는 ‘이전 20경기’를 맞춥니다. ‘이전 20경기’는 지금의 21~40번째 경기이며, 지난번 방문 때 저장한 화면을 뜻하지 않습니다.
  3. ‘최신순 · N경기 표시 중’과 매치 목록의 맵·승패·날짜를 확인합니다. 날짜만 같다고 같은 경기로 단정하지 말고, 필요하면 경기를 펼쳐 상세 시각도 함께 봅니다.
  4. 최신 데이터가 필요하면 검색창 옆 새로고침 버튼을 사용하고 로딩·갱신 상태를 확인합니다. 갱신 실패나 기존 데이터 표시 안내가 남아 있다면 새 기록으로 계산하지 않습니다.

짧은 간격의 일반 재검색은 캐시를 다시 보여 줄 수 있습니다. 새로고침 후에도 공개 데이터 반영 시차 때문에 경기 목록이 같을 수 있으므로, 조회 시각과 최신 경기 시각을 구분해 적어 두세요.

재조회 전후 네 항목을 기록합니다

직접 기록용 · 이전 수치는 재조회 전에 메모합니다
항목조회 A에 적을 내용조회 B에서 확인할 내용
경기 수·범위조회 시각, 유형·구간, 실제 경기 수, 최신·가장 오래된 경기새로 들어온 경기와 빠진 경기, 두 조회에 겹치는 경기
승률승리 수 / 실제 경기 수와 표시 승률같은 유형·구간에서 분모와 승리 수가 어떻게 바뀌었는지
K/D같은 구간의 표시 값과 필요하면 킬·데스 합계경기별 퍼센트의 평균 대신 구간 합계 기준으로 비교
맵 구성각 맵의 경기 수 / 전체 경기 수새 경기와 빠진 경기의 맵, 전체 맵 비중 변화

최근 20경기가 이미 채워졌다면 새 경기가 들어와도 표시 경기 수는 20으로 유지됩니다. ‘20 → 20’만으로 추가 경기가 없었다고 판단하지 마세요. 즐겨찾기나 최근 검색으로 다시 방문하더라도 비교할 이전 수치는 직접 메모해 둡니다.

가상 예시: 4경기가 들어와도 20경기입니다

조회 A의 최근 20경기를 최신순으로 A1~A20이라고 하겠습니다. 그 뒤 같은 유형의 새 경기 N1~N4가 들어오면 최근 구간에는 새 4경기와 기존 A1~A16이 남고, A17~A20은 빠집니다. 두 조회에는 16경기가 겹칩니다.

가상 예시 · 최근 20경기의 교체와 승률 변화
구분경기 수승·패계산
조회 A2010승 10패10 ÷ 20 = 50%
구간에서 빠진 A17~A2042승 2패기존 승리에서 2승 제외
새로 들어온 N1~N443승 1패새 승리 3승 추가
조회 B2011승 9패(10 − 2 + 3) ÷ 20 = 55%

승률은 50%에서 55%로 5%p 올랐습니다. 새 4경기의 승률 75%와 전체 최근 구간의 승률 55%는 다른 값입니다. 또한 A와 B는 서로 독립된 20경기 두 묶음이 아니므로, 이 변화만으로 실력 상승을 확정하지 않습니다.

변화가 없거나 방향이 엇갈릴 때

  • 최신 경기가 같음: 새 결과가 아직 반영되지 않았을 수 있습니다. 조회 횟수를 늘리는 대신 갱신 상태와 매치 유형을 확인합니다.
  • 승률만 변함: 빠진 경기·추가된 경기의 승패와 맵 구성을 먼저 확인하고, K/D가 유지됐는지도 따로 기록합니다.
  • 닉네임·유형·표본이 다름: 비교 조건이 맞을 때까지 변화량 해석을 보류합니다. 공개 기록만으로 알 수 없는 상대 실력이나 전술을 원인으로 붙이지 않습니다.

출처와 적용 범위
