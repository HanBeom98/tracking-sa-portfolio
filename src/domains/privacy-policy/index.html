처리하는 정보

  • 회원 기능: Firebase Authentication을 통해 이메일 주소, 인증 식별자와 로그인 상태를 처리합니다.
  • 프로필과 게시판: 사용자가 설정한 닉네임, 작성한 게시물·댓글과 작성 시각을 처리합니다.
  • 전적 검색: 사용자가 입력한 서든어택 닉네임과 경기 식별자를 NEXON Open API 조회에 사용합니다.

이용 목적과 보관

회원 인증, 닉네임 중복 방지, 게시판 제공, 서비스 오류 분석, 부정 이용 방지, 이용 현황 측정과 광고 제공을 위해 정보를 사용합니다. 회원 정보와 작성 콘텐츠는 회원 탈퇴 또는 삭제 요청 시 관계 법령과 보안상 필요한 범위를 제외하고 삭제합니다. 접속·보안 로그는 각 호스팅 및 분석 서비스의 보관 설정과 정책에 따라 처리됩니다.

제3자 서비스와 쿠키

Tracking SA는 Firebase, Google Analytics, Google AdSense, Microsoft Clarity, Cloudflare와 NEXON Open API를 사용합니다. 이들 서비스는 인증, 보안, 이용 통계, 광고 표시와 성과 측정을 위해 쿠키, 로컬 저장소, IP 주소 또는 기기·접속 정보를 처리할 수 있습니다.

Google의 광고 쿠키 사용 방식과 맞춤 광고 설정은 Google 광고 센터에서 확인하거나 변경할 수 있습니다.

TEST 결제와 복구 정보

AI 이용권의 TEST 결제는 토스페이에서 구매자 인증을 진행합니다. 구매자는 인증 정보와 결제 비밀번호를 토스 화면에 직접 입력하며, 사이트 문의에 보내지 않습니다. 서버는 TEST 주문번호·결제 식별 정보·처리 상태를 실제 회원 구매 원장과 분리해 처리합니다. TEST 완료로 실제 대금이나 회원 이용권이 발생하지 않고 유료 AI 분석도 실행하지 않습니다.

일반 상품 구매 TEST는 기존 Firebase 회원 인증을 사용하며, 서버는 인증된 계정에 묶인 TEST 주문만 처리합니다. 같은 브라우저의 계정별 복구 사본에는 주문번호와 24시간 복구 기한만 보관합니다. 이 결제 복구 사본에는 인증 토큰·결제 API 키·접근코드를 저장하지 않습니다.

이전 운영 TEST 도구의 새 탭 복귀 정보는 입력한 접근코드로 암호화하여 같은 브라우저에 보관하며 24시간 안에만 복구할 수 있습니다. 접근코드 원문은 브라우저 저장소에 보관하지 않습니다. 브라우저 데이터 삭제 시 복구 사본도 삭제됩니다. 브라우저의 24시간 복구 기한과 서버 TEST 기록의 보관은 별개입니다.

가맹 심사 기간에는 비회원도 TEST 결제창을 확인할 수 있습니다. 동의 후 TEST 버튼을 누르면 임의로 생성한 방문자 식별값이 담긴 서버 서명 쿠키를 발급하며, 같은 방문자의 TEST 주문 확인에만 사용합니다. 쿠키는 Secure·HttpOnly·SameSite=Lax로 설정하고 발급 후 24시간 동안 유효합니다. 비회원 복구 사본에는 주문번호·복구 기한·개인을 직접 식별하지 않는 임시 식별값만 저장합니다. 회원가입이나 유료 AI 제공은 발생하지 않습니다. 쿠키·브라우저 저장소 삭제 또는 유효기간 경과 시 비회원 주문 복구가 제한됩니다. 서버 TEST 기록의 보관은 브라우저의 24시간 복구 기한과 별개입니다.

정식 판매 전에는 실제 결제·환불 및 AI 제공에 필요한 처리 정보와 보관 기준을 별도로 안내합니다. 현재 유료 AI 제공자에게 회원 리플레이를 자동 전송하는 판매 기능은 열지 않았습니다. 현재 TEST 안내를 확인할 수 있습니다.
