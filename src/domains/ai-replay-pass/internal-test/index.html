운영 TEST 기록 관리

이전 TEST 거래 확인·복구를 위한 운영 도구입니다. 상품 구매는 이용권 페이지에서 진행하세요.

심사용 TEST 결제

별도로 전달받은 심사용 접근코드가 필요합니다. 로그인 없이 상품을 확인할 수 있고, TEST 진행만 접근코드로 제한합니다. 표시 금액은 3,300원이며 TEST 승인 결과는 실제 이용권 잔액에 반영되지 않습니다.

  1. 아래 접근코드를 입력하고 TEST 확인 항목을 선택합니다.
  2. TEST 주문 준비 → TEST 결제창 준비 → 토스 TEST 결제창으로 이동합니다.
  3. 심사 담당자 본인의 토스 앱에서 구매자 인증을 완료하고 사이트로 돌아옵니다.
  4. 같은 코드를 입력한 뒤 기존 주문 확인 → 구매자 인증 후 TEST 승인 확인을 누릅니다. 새 탭이면 보관된 TEST 주문 복구부터 진행합니다.

하루에 준비할 수 있는 TEST 주문 수와 전체 한도를 제한하고 있습니다. 한도 안내가 나오면 운영자에게 문의해 주세요. 새 주문·승인은 자동으로 반복 요청하지 않습니다.

접근코드는 저장하지 않습니다. 주문 복구 정보는 이 코드로 암호화하여 같은 브라우저에 저장하며, 24시간 안에만 복구할 수 있습니다. 토스에서 돌아오거나 새 탭을 열면 같은 코드를 다시 입력해 주세요. 브라우저 데이터 삭제·복구 기간 경과 후에는 운영자에게 문의하세요.

접근코드와 TEST 확인 항목을 입력한 후 주문 준비를 누르세요. 현재는 실제 결제가 아닌 TEST입니다.
