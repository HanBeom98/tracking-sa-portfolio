Tracking SA 편집 원칙

Tracking SA의 가이드, 설명 문서, 서비스 소개 문서는 검색 엔진을 위한 형식적인 텍스트가 아니라 실제 사용자가 전적 데이터를 이해할 수 있도록 쓰는 안내 문서입니다. 이 문서는 그 작성 기준을 공개합니다.

설명 콘텐츠의 작성 목적

전적 숫자만으로는 사용자가 의미를 바로 이해하기 어렵기 때문에, 가이드 문서는 최근·이전 20경기, 최근 31일 활동, VS 비교와 리그 허브 같은 실제 화면을 기준으로 읽는 법을 설명합니다.

작성 기준

  • 실제 서비스 화면에서 확인 가능한 항목만 설명합니다.
  • 추정이나 단정이 필요한 문장은 피하고, 확인 가능한 범위와 해석 범위를 구분합니다.
  • 전적 검색 도구와 별개로 문서만 복제하지 않고, 사용자가 다음에 무엇을 봐야 하는지 연결합니다.
  • 운영 문서에는 운영 주체, 연락 수단, 업데이트 날짜를 남깁니다.

검수 범위

  1. 링크가 실제 공개 페이지로 연결되는지 확인합니다.
  2. 설명 문서가 현재 서비스 구조와 어긋나지 않는지 점검합니다.
  3. 서비스 구조가 바뀌면 관련 가이드와 운영 문서를 함께 수정합니다.
  4. 오류 제보가 들어오면 확인 후 문서 또는 안내 문구를 갱신합니다.

자동 생성과 수동 작성의 구분

전적 데이터는 서비스 기능에서 불러오고, 가이드 문서와 운영 안내는 사람이 직접 작성하고 수정합니다. 숫자 데이터와 설명 문장을 같은 종류의 콘텐츠로 취급하지 않으며, 설명 문서는 사용자가 전적을 읽는 데 필요한 맥락을 추가하는 역할을 합니다.

가이드 문서는 특정 키워드를 채우기 위한 대량 생성 페이지로 운영하지 않습니다. 서비스 구조와 직접 연결되는 주제만 유지하고, 중복 문서는 늘리지 않는 것을 원칙으로 합니다.
