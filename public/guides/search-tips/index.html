닉네임 검색 정확도 높이는 법

전적 검색에서 가장 흔한 실수는 기억나는 별칭으로만 검색하는 것입니다. 비슷한 닉네임, 특수문자, 공백 차이 때문에 다른 플레이어를 보게 되는 경우가 적지 않아서 기본 원칙을 정리했습니다.

입력값부터 확인하기

디스코드 별칭 대신 게임 내 현재 닉네임을 복사하세요. 영문 I(대문자 아이), l(소문자 엘), 숫자 1은 모양이 비슷해도 다른 문자입니다. 특수문자를 빼거나 닮은 문자로 바꾸지 마세요. 결과의 닉네임과 프로필을 확인하고 최근 경기 날짜·맵을 대조한 뒤 즐겨찾기에 추가하세요.

캐릭터 조회와 경기 조회를 구분하기

‘캐릭터를 찾을 수 없습니다’가 나오면 현재 닉네임을 다시 확인합니다. ‘경기 기록 조회에 실패했습니다’는 정상적인 0경기가 아닙니다. ‘일부 경기 기록을 확인하지 못했습니다’가 표시되면 해당 결과만으로 전체 활동량이나 실력 하락을 단정하지 마세요.

응답 지연과 요청 제한

‘전적 조회 응답이 늦어지고 있습니다’는 대기 시간 초과입니다. 잠시 후 다시 검색하세요. ‘전적 조회 요청이 잠시 제한되었습니다’는 요청이 많아 기다려야 하는 상태입니다. 새로고침을 연속으로 누르지 마세요. 문제가 계속되면 조회 시각과 정확한 오류 문구를 문의로 전달하세요.

프로필은 있지만 기록이 적다면

공개 분석은 폭파미션의 경쟁 모드 기록을 사용합니다. 다른 모드에서 플레이한 기록이 없을 수 있으며 최근 20경기는 최대 개수입니다. 최근 31일 활동은 달력 기간이 기준이라 같은 집계가 아닙니다. 비교할 기록이 부족하면 비교 표본 부족으로 표시합니다.

최신 경기 반영과 오류 제보

반복 조회에는 캐시가 사용됩니다. 최신 데이터로 갱신 버튼을 한 번 누른 뒤 완료를 기다리세요. 제공처의 반영 시차까지 없애는 기능은 아닙니다. 닉네임·조회 시각·매치 유형·오류 문구를 문의 페이지로 전달하면 확인에 도움이 됩니다. 비밀번호나 인증 코드는 보내지 마세요.
