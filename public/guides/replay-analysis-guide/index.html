‘여러 경기 비교’는 여러 사람의 실력을 순위로 매기는 기능이 아닙니다. 같은 선수의 기록을 경기별로 놓고 표본과 차이를 확인하는 기능입니다.

2. 공식 리플레이 JSON을 준비하세요

  1. 서든어택 공식 병영수첩에서 캐릭터의 기록을 찾습니다.
  2. 리플레이가 제공되는 경기의 상세 기록을 열고 JSON 파일을 저장합니다. 분석실에는 저장된 .json 파일을 넣습니다.
  3. 다운로드 폴더에서 파일을 찾고, 파일당 최대 2MB인지 확인합니다. 여러 경기를 비교하려면 서로 다른 경기의 파일을 준비하세요.

홈의 ‘내 리플레이 분석’에서도 파일을 선택하거나 끌어놓을 수 있습니다. 1개는 한 경기 분석, 2~5개는 같은 선수의 경기 비교로 이어지며 파일을 다시 선택할 필요가 없습니다. 홈으로 돌아가도 현재 페이지 안의 작업은 유지되지만, 새로고침하면 파일을 다시 선택해야 합니다.

동영상·스크린샷이나 이름만 .json으로 바꾼 파일은 분석할 수 없습니다. 공식 사이트에서 특정 경기의 리플레이 파일을 제공하지 않는 경우 Tracking SA가 그 파일을 새로 만들어 가져오지는 않습니다.

처음에는 파일을 따로 편집하지 않고 저장한 원본 그대로 사용하세요. 비교할 때 동일한 파일을 복사해서 두 개 넣어도 서로 다른 경기 두 개로 계산하지 않습니다.

3. 기본 분석부터 보고, 필요한 장면으로 이동하세요

  1. ‘한 경기 상세 분석’에서 파일을 선택하거나 선택 영역에 끌어놓습니다.
  2. ‘분석할 플레이어’에서 본인 또는 확인할 선수를 고르고 ‘이 플레이어 분석’을 누릅니다.
  3. 경기 흐름 재생에서 시간을 이동하거나 라운드를 선택합니다. 현재 생존자·사건 기록과 그래프를 함께 확인하세요.
  4. 핵심 장면의 ‘라운드 보기’, 처치·사망 필터, 상세 분석 항목으로 근거를 더 확인합니다.

기본 분석과 재생은 전력 조회를 기다리지 않고 표시됩니다. 경기 유형 자동 확인이나 전력 조회가 늦거나 실패해도 파일에 있는 라운드 기록은 먼저 볼 수 있습니다. 전력 정보가 준비되면 전력 패널만 갱신되며 재생 위치는 유지됩니다.

결과 상단의 수치와 핵심 장면부터 확인하세요. ‘핵심 장면 / 경기 재생 / 세부 기록’으로 이동할 수 있으며, 세부 기록에는 기록 진단·추가 전력·기록 해설 예시·생존·투척·라운드 항목을 모았습니다. 계산 기준과 검증 보류 안내를 함께 확인하세요.

같은 결과 화면 안에서도 데이터 출처가 다릅니다
부분사용하는 정보조회가 안 될 때

당시 전력 비교는 경기 후 7일 이내의 리플레이를 대상으로 합니다. 날짜를 확인할 수 없거나 이 기간이 지난 파일은 전력 비교를 제외해도 기본 분석이 가능합니다. 닉네임 변경 등으로 외부 정보를 찾지 못한 경우도 곧바로 ‘기록 없음’이나 ‘실력이 낮음’으로 해석하지 않습니다.

장면을 남길 때는 재생 위치를 맞춘 뒤 ‘이 시점 이미지’를 사용하세요. 경기 전체 요약은 ‘이미지 공유’로 별도로 만들 수 있습니다. 두 기능 모두 원본 게임 영상을 생성하는 기능은 아닙니다.

수치와 라운드 표를 함께 보관하려면 결과 상단의 ‘보고서 / PDF’를 누르세요. 미리보기에서 확인한 뒤 ‘인쇄 / PDF 저장’을 누르고 브라우저의 ‘PDF로 저장’을 선택할 수 있습니다. 공식 경기 총계와 검증 라운드 집계를 구분하며, 검증 보류 라운드는 표에 남기고 평균·주요 장면에서는 제외합니다. 닉네임·경기 시각이 포함되므로 공유 전에 확인하고, URL 등의 자동 표시는 브라우저 머리글·바닥글 설정에서 끌 수 있습니다.

4. 그래프: 경기 승리 추정치와 상황 우세 지수

랭크전 R 유형은 현재 점수와 전후반 3선승 규칙, 조기 종료·골든라운드를 반영한 경기 승리 추정치(%)를 표시합니다. 전반 3:0으로 공수교대해도 우세가 유지되며, 상대가 남은 라운드로 동점을 만들 수 없으면 승리 확정입니다. 현재 라운드는 생존 인원·C4 상태로 보정하고 이후 라운드는 동등 전력을 가정합니다. 학습·검증된 실측 승률이 아니므로 참고용으로 사용하세요. 다른 유형은 기존 상황 우세 지수(점)를 표시합니다. 아래 가상 랭크전 샘플과 홈 미리보기는 경기 승리 추정치를 사용합니다.

그래프는 A팀 기준 한 개의 선으로 읽습니다. 가운데 50은 균형, 50보다 높으면 A팀 우세, 낮으면 B팀 우세입니다. 청록/빨강과 범례를 함께 확인하세요. 두 팀의 계산 기준은 그대로이며 검증이 보류된 구간은 선을 이어 그리지 않습니다.

R 이외 유형의 상황 우세 지수는 현재 생존 인원 차이, 이미 끝난 라운드 점수, 기록된 폭탄 설치 상태를 정해진 규칙으로 요약한 참고 점수입니다. 실제 경기 결과로 학습·검증한 승리 확률이 아닙니다. 그래프 눈금과 별개로 계산된 표시는 5~95점 범위로 제한됩니다.

분석실의 ‘샘플로 한 경기 체험’에서 1라운드를 선택하고 시간을 옮겨 보세요. 폭탄 설치가 없고 앞서 끝난 라운드도 없는 상태에서는 다음과 같이 변합니다.

  1. 라운드 시작50.0%A팀 5명 · B팀 5명
  2. 8초 · 상대 1명 처치52.3%A팀 5명 · B팀 4명
  3. 18초 · 아군 1명 사망50.0%A팀 4명 · B팀 4명

8초의 현재 라운드 가정값은 50 + 40 × (5 − 4) ÷ 5 = 58%입니다. 이를 현재 라운드 승패 이후의 남은 경기 경로에 반영하면 경기 전체 승리 추정치는 52.3%입니다. 점수가 0:0인 이 예시에서는 인원이 다시 같아지면 50%로 돌아옵니다. 앞선 점수가 있으면 새 라운드가 시작해도 그 우세를 유지합니다.

실제 기록에서는 앞선 라운드 점수나 폭탄 상태가 다를 수 있어 같은 생존 인원이라고 항상 같은 점수가 나오지는 않습니다. 지수가 내려간 시점은 다시 볼 장면을 찾는 출발점이지, 특정 선수의 실수를 입증하는 결론이 아닙니다.

옅은 선은 전체 기록, 진한 선은 현재 재생 시점까지의 기록입니다. ‘양 팀 전력 비교’의 예상치와 재생 그래프는 입력과 계산 방식이 다르므로 두 값을 같은 확률처럼 비교하지 마세요.

5. 중간 이탈·재접속은 기록 근거가 있을 때 연결합니다

경기 중 나갔다가 돌아온 선수가 있으면 단순히 참가자 수가 줄었다는 이유만으로 사망 처리해서는 안 됩니다. 분석실은 확인 가능한 참가자 ID와 이탈·복귀 관련 기록으로 상태를 구분하고, 기록이 일관된 경우 재생 흐름을 복원합니다.

한 가지 상태로 모두 합치지 않고 근거를 확인합니다
보이는 상태확인할 것피해야 할 해석
이탈해당 시점에 기록에서 빠진 참가자와 ID나갔으니 반드시 사망했다고 보기
복귀·재진입같은 참가자로 연결되는지, 이후 상태가 확인되는지같은 이름이니 무조건 같은 선수로 합치기
확인 보류·인원 확인 보류누락·충돌·모호한 순서 등 판정에 필요한 기록빈 구간을 0점·패배나 확정적인 인원 열세로 읽기

모든 파일의 모든 재접속을 복원할 수 있다는 뜻은 아닙니다. 근거가 부족한 구간은 임의의 생존자 수나 우세 지수를 만들지 않고 판정을 보류할 수 있습니다. 이때도 표시 가능한 사건 기록은 함께 확인하세요.

그래프가 비어 있거나 상태가 보류되어 있다면 먼저 해당 라운드의 안내와 사건 기록을 보세요. 매끈한 선을 만들기 위해 확인되지 않은 구간을 이어 그리는 것보다, 어디까지 확인 가능한지 구분하는 것이 중요합니다.

6. 여러 경기에서 같은 선수를 비교하는 순서

  1. ‘여러 경기 비교’ 탭에서 파일 선택창을 열어 JSON 2~5개를 함께 고릅니다. PC에서는 Ctrl 또는 Shift를 사용할 수 있습니다. 새로 고른 목록은 이전 목록을 대체합니다.
  2. 공통으로 등장하는 선수 중 ‘비교할 선수’를 고릅니다. 경기 ID 중복·지원하지 않는 파일 등 제외 사유가 있으면 먼저 확인합니다.
  3. 각 행의 ‘검증 / 제공 라운드’를 확인한 뒤 처치·사망, 라운드당 처치, 생존율과 평균 생존을 비교합니다.
  4. ‘과제 전후 확인’을 열면 직접 ‘기준 경기’와 ‘이후 경기’를 지정하고 확인할 지표를 선택할 수 있습니다.

닉네임보다 선수 ID가 기준입니다. 이름이 달라져도 ID가 같으면 연결하고, 이름이 같아도 ID가 다르면 합치지 않습니다. 두 개 이상의 서로 다른 경기에서 같은 선수 ID가 확인되어야 비교할 수 있습니다.

위장 닉네임을 쓴 경기와 원래 닉네임으로 돌아온 경기를 넣더라도 ID가 같으면 같은 선수로 비교할 수 있습니다. 파일 순서나 닉네임이 같다는 것만으로 연결하는 방식은 아닙니다.

기준·이후 그룹은 자동으로 날짜순 지정되지 않습니다. 비교할 시점과 목적을 확인해서 직접 구분하세요. 맵·공수·상대·라운드 길이가 다를 수 있으므로 지표가 좋아졌다는 사실만으로 훈련이나 코칭의 효과가 증명되지는 않습니다.

7. 샘플 두 경기의 수치를 직접 확인해 보세요

가상 샘플의 실제 계산 결과입니다.
아래는 실사용자의 전적이나 훈련 성과가 아닙니다. 분석실의 ‘샘플로 여러 경기 비교’를 누른 뒤 ‘체험 플레이어’를 선택하면 같은 구성을 확인할 수 있습니다. 샘플 데이터가 바뀌면 표시값도 달라질 수 있습니다.

현재 두 파일은 각각 6라운드이며 12라운드 모두 집계 가능한 상태입니다. 화면의 소수점 표시는 반올림합니다. 표가 넓으면 좌우로 밀어 보세요.

라운드 생존율: 생존 5라운드 ÷ 검증 12라운드 × 100 ≈ 41.7%
평균 생존: 생존 시간 합계 440초 ÷ 검증 12라운드 ≈ 36.7초

이 사례는 두 파일의 라운드 수가 같지만, 실제 파일의 라운드 수는 다를 수 있습니다. 합계는 검증된 라운드의 합을 기준으로 계산합니다. 검증할 수 없는 라운드나 해당 선수가 없는 경기를 성적 0으로 채우지 않습니다.

두 번째 샘플의 평균 생존이 더 길다는 것만으로 실제 플레이가 좋아졌다고 판단할 수는 없습니다. 우선 라운드 수·생존 비율·공수와 사건 기록을 함께 확인하는 연습에 사용하세요.

8. 사용 중 자주 막히는 부분

파일은 두 개인데 비교가 안 됩니다.
서로 다른 경기인지, 두 경기 이상에 같은 선수 ID가 있는지, 파일 형식·크기와 제외 사유를 확인하세요. 같은 파일을 이름만 바꾸어 복사하면 별도 경기로 늘어나지 않습니다.
전체 킬 수와 비교 표의 킬 수가 다릅니다.
요약 기록과 검증 라운드 집계는 범위가 다를 수 있습니다. 비교 표의 ‘검증 / 제공 라운드’를 먼저 확인하세요.
전력 정보는 안 뜨는데 재생은 됩니다.
두 부분의 데이터 출처가 다릅니다. 날짜·경기 유형·외부 조회 실패 안내를 확인하고 기본 분석은 계속 사용할 수 있습니다.
새로고침 후 선택한 파일이 사라졌습니다.
파일·분석 결과·비교 설정은 서버에 저장하지 않습니다. 원본 JSON은 별도로 보관하고 다시 선택하세요. 이미지 공유는 원본 파일의 백업을 대신하지 않습니다.
그래프로 실제 시야나 사망 원인을 확정할 수 있나요?
기록에 없는 실제 시야·음성·플레이 의도는 복원하지 않습니다. 이 기능은 JSON에 남은 사건을 정리하는 분석·이벤트 재생이며, 원본 게임 영상이나 생성형 AI의 판단이 아닙니다.

출처와 확인 범위

파일 출처는 넥슨 서든어택 공식 병영수첩입니다. 표시 방식·집계 기준·샘플 계산은 Tracking SA의 현재 무료 분석 구현을 따릅니다. 가상 샘플을 실제 경기 관측 자료로 사용하지 않습니다.

사용자가 선택한 JSON은 기기 안에서 읽습니다. 한 경기 전력 비교에 필요한 경기 ID·닉네임은 넥슨 OpenAPI 조회에 사용하지만 원본 JSON과 분석 결과를 서버나 DB에 별도로 저장하지 않습니다. 여러 경기 비교와 샘플 체험은 전력 조회 없이 기기 안에서 처리합니다.
