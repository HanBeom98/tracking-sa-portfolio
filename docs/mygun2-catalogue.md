# 마이건2 도감

2026-11-05 작성. `/guides/mygun2/`에서 시리즈·총기·기능을 검색하고 최대 세 시리즈를 비교한다. 가이드 허브와 빌드의 사이트 검색 인덱스에서 접근한다. 정적 HTML·CSS·ES 모듈과 로컬 이미지로 동작하며 새로운 API·DB·유료 AI·계정별 수집을 추가하지 않는다.

진입 경로는 공통 상단 메뉴의 ‘마이건2 도감’, 홈의 총기 이미지 바로가기, 가이드 허브 첫 화면의 도감 카드다. 가이드 허브의 문서는 시작하기·전적 지표 해석·리그와 서비스로 묶고 기존 문서 주소를 유지한다. 메뉴는 모바일에서도 기존 접이식 내비게이션을 사용한다.

## 자료와 이미지

- 기준: [넥슨 마이건2 공식 가이드](https://guide.sa.nexon.com/guide/45), 2026-11-05 실제 원문 대조. 초기 검색 도구의 점검 안내와 달리 직접 가져온 공식 HTML은 정상 본문이었다.
- 수록: 이온·에보·서클·헌트·제노·노바·로얄·럼블·더블·이블·마블·노블 12개 시리즈, 총기 이미지 151개. 초기 공식 가이드 149개에 2026-11-19 공식 업데이트의 이온 2개를 추가했다. 이것은 고유 무기 151개나 세트 계산기 기준 151그룹을 의미하지 않는다. Circle Black 등의 외형별 표도 총기 목록에 포함한다.
- 이미지는 공식 표의 해당 셀과 대응시켰다. [이미지 출처](mygun2-image-sources.csv)에 공식 무기 그룹명·원본 URL·로컬 경로·원본 SHA-256을 보관한다.
- 세트 보상 이미지 45개는 2026-11-06 공식 세트 표에서 세트 수·보상 이름과 대조했다. 동일 세트 수에 여러 보상이 있는 이블도 각각의 이미지를 대응시켰다. 원본 PNG 45개 총 515,612바이트를 변경 없이 `images/rewards/`에 보관하며 [세트 보상 이미지 출처](mygun2-set-image-sources.csv)에 원본 URL·SHA-256·크기를 기록한다. 총기 상세창과 시리즈 안내 양쪽에서 이미지·이름·효과 카드로 표시하며, 기본 접힘과 지연 로딩을 사용한다. 이미지 로딩이 실패해도 보상명·세트 수·효과는 남는다. 기존 총기 이미지 수 149개에는 이 세트 보상 이미지 45개를 합산하지 않는다.
- 투명 여백 때문에 킷 등이 작게 보이지 않도록 PNG의 알파 경계를 `imageBounds`로 보관한다. 브라우저의 표시 영역만 맞추고 원본 파일·픽셀·SHA-256은 변경하지 않는다.
- 공식 PNG 149개 총 2,372,636바이트를 같은 픽셀·크기의 무손실 WebP 총 1,559,602바이트로 재인코딩했다. 게임 외형을 그리거나 변경하지 않았다. 목록과 상세 모두 이미지 공간을 확보하고, 아래쪽 이미지는 지연 로딩한다. 모든 이미지를 첫 화면에서 받지 않는다.
- 하나의 그룹 이미지가 셀에 나열된 모든 소음기·착검·레벨의 모습과 같다는 뜻은 아니다. 목록·상세·확대에 대표 외형임을 표시한다. 이미지 로딩이 실패해도 무기명과 설명은 남긴다.

## 기능과 경계

- 카드에서는 대표 이미지·기능 분류·핵심 조건을 요약한다. 상세에서는 조건·유지/해제·총기 이미지·기본 레벨·세트 보상·공식 출처를 제공한다.
- 검색은 한글·영문·총기명·기능 설명을 사용하고 전각 영문과 구두점 차이를 정규화한다. 기능 및 총기명 필터와 함께 적용한다.
- 총기 검색·총기별 필터를 적용하면 결과 카드에는 해당 총기의 이미지와 이름을 표시한다. 시리즈명·기능만 검색하면 기존 대표 이미지를 유지하며, 상세 화면은 시리즈 전체 총기를 제공한다. 검색 총기와 총기별 필터가 충돌하면 빈 결과로 안내한다.
- 비교는 두세 시리즈를 동일한 항목으로 표시한다. 필터를 바꿔도 선택을 유지하며 네 번째 선택을 제한한다. 실제 기본 총기 성능의 순위를 추정하지 않는다.
- 네이티브 dialog로 비교·이미지 확대를 제공하고 닫기/Escape·초점 복귀를 확인한다. 닫힌 dialog는 명시적으로 숨긴다.
- 레벨별 예외는 원문의 기본 1~50 표를 보존한다. Noble 개조 대상·고레벨 혜택은 이 기본 표에 일반화하지 않고 공식 개조 안내로 연결한다.
- 세트 표의 rowspan을 펼쳐 같은 요구 그룹 수에 속하는 복수 보상을 보존했다. 단순 소지품 개수나 보유 아이템 자동 계산 기능은 없다. 공지 이후 추가되거나 변경된 내용은 다음 검토 전까지 반영되지 않을 수 있다.
- 사용자 화면은 게임에서 익숙한 ‘3세트 효과’·‘6세트 효과’ 표현을 사용한다. 원문의 그룹 집계 기준은 유지하며 같은 대상의 변형은 중복으로 세지 않는다. 이미지 수는 ‘총기 이미지’로 표시하여 세트 수와 구분한다.

## 유지보수

### 2026-11-19 이온 신규 무기

[11/19 공식 업데이트](https://sa.nexon.com/news/update/view.aspx?n4ArticleSN=881)의 SCAR_v2(I)/(IS) Eon과 GSR-6(I)/(IS) Eon을 추가했다. 이온은 8개 무기 그룹이며 세트 보상은 기존 3·6세트를 유지한다. 공지상 9세트 보상은 추후 공개 예정이다. 기본 성능·장전 수는 기존 SCAR_v2·GSR-6 자료를 사용한다.

공식 GIF 두 개의 여섯 번째 프레임(0 기준 5)을 원본 픽셀·크기 330×335 그대로 정적 무손실 WebP로 저장했다. 애니메이션 전체를 다운로드하지 않으며 두 WebP는 총 20,348바이트다. 원본 GIF URL·SHA-256은 이미지 출처 CSV에 기록했다. 페이지에는 기존 가이드 대조일과 신규 공지 대조일을 따로 표시한다.

### 무기 상세와 기본 성능 참고값

2026-11-06 상세창 폴리싱: 총기 이미지·시리즈/레벨 배지와 성능 게이지를 나란히 배치하고, 발동 조건·유지/재사용을 두 카드로 구분했다. 장전 수·무한 예비탄약과 선택 총기의 추가 효과는 분리한다. 출처/확인일/원문 링크는 상세창에서 제거하되 데이터의 출처와 SHA-256, 이 문서와 점검 기록에는 보관한다. 발동 상세·주의사항, 레벨별 예외, 세트 표는 기본 접힘 상태로 제공한다. 성능 수치를 확률로 해석하지 않는 설명과 TAS 모드 구분, Nova 사용 횟수 미확인 안내는 유지한다. 스크롤해도 닫기 버튼이 보이도록 제목을 고정한다.

2026-11-06 GSR-6 정정: 새로 제공된 GSR-6 Luna 인게임 화면의 대미지 99·연사력 40·명중률 100·총기반동 50을 반영했다. 이전 화면에서 옮긴 47/40/47/47은 이 값으로 대체하고 출처 SHA-256·확인일도 갱신했다. 마이건2 탄약 표시는 ‘5발 / 무한’이다.

같은 날 추가 캡처 기준 HK416_v2는 41/76/87/64, MSR-200은 100/0/100/85, GAL-1_v2는 44/80/87/79, DSG-12는 80/12/48/93으로 정정했다(대미지/연사력/명중률/총기반동 순). 38개 기본형을 공식 가이드 16종·사용자 캡처 22종에 재대조한 결과와 점검 범위는 [수치 점검 기록](mygun2-stats-audit-2026-11-06.md)에 남겼다.

목록 카드와 시리즈 갤러리의 총기 사진을 누르면 큰 이미지·기본 무기 참고 스펙·시리즈 기능·총기별 예외·공통 레벨 표를 연다. `weapon-specs.js`에는 기본형 38개가 있다. 16개는 [넥슨 주무기 가이드](https://guide.sa.nexon.com/guide/39)의 2026-08-27 수정본을 2026-11-05 대조한 값이며, 22개는 사용자 제공 인게임 화면으로 확인했다. 공식 가이드는 원문의 `--value` 성능 막대 값 네 개와 장탄수, 무기명, 분류, 해당 제목 앵커를 보관한다. 인게임 자료는 출처 종류·화면 무기명·원본 SHA-256·확인일을 따로 보관하고 공식 웹 출처로 표시하지 않는다. 표기 수치를 실제 피해량·명중 확률·초당 발사 수로 환산하지 않는다. 연사력 0도 원문 표기 그대로 보존한다.

인게임 확인 총기는 AWP·Specter·VS-9·TSR·TAS·TAC-9·SCAR_v2·Peacemaker·PPS·P90_v2·NA-34·Mak-12·MSR-200·MP-X3·HK416_v2·GSR-6·GAL-1_v2·G18·DSG-12·DRT-6·ANR·XM68이다. XM68은 65/53/88/80, 원문 장탄수는 20/80발이다. GAL-1_v2는 새 Re:vival 캡처를 사용하고, DRT-6 자료는 출처 무기명에 Noble Lv.50을 명시한다. 레벨·진화 효과는 별도 구역에서 확인한다.

같은 기본 총기의 스킨들은 공통 기본 스펙을 사용한다. 마이건2의 레벨·진화·개조로 생기는 추가 효과는 별도 구역에서 표시한다. AK47 Light/Heavy는 성능이 다른 기본형으로 따로 대응하며, 하나의 공식 이미지가 양쪽을 묶으면 두 기본형을 함께 제시한다. 모든 마이건2의 예비탄약이 무한이라는 운영자 확인을 반영하여 `mygunAmmo()`가 ‘장전 수 / 무한’을 표시한다. 예를 들어 AWP는 ‘5발 / 무한’, XM68은 ‘20발 / 무한’이다. 원문 장탄수 데이터는 출처 대조용으로 보존하며 일반 무기의 예비탄약 수를 마이건2 화면에 적용하지 않는다. TAS는 기본 모드 수치만 표시하고 컴팩트 모드 수치를 추정하지 않는다. 향후 자료가 없는 총기는 성능과 장전 수를 미확인으로 표시한다. `weapon-detail.js`는 확인된 에보 2단계 장탄수, 서클 잔탄 조건과 윈체스터·G18 예외만 선택 총기에 맞춰 강조한다.

업데이트 시 기본형 수치와 마이건2 원문을 각각 대조하고 원문 수정일·확인일·출처를 갱신한다. 원문에 없는 수치와 레벨별 수치의 자동 합산은 추가하지 않는다. 데이터는 정적 파일이며 사용자 조회 시 공식 사이트/API/DB를 호출하지 않는다. 페이지의 JS·CSS는 상대 경로로 선언하여 기존 빌드가 내용 기반 버전을 붙이도록 한다. 이전 이미지 확대 코드가 캐시에 있어도 새 상세창과 섞이지 않는지 브라우저 검사로 확인한다.

원문에서 시리즈별 조건·총기별 예외·레벨 표·세트 표를 다시 확인한 뒤 `src/domains/guides/mygun2/catalog.js`를 수정한다. 원본 이미지를 변경하면 출처 CSV·로컬 WebP·크기 정보도 함께 갱신한다. 임의 URL 자동 수집이나 예약 크롤링은 운영하지 않는다. 숫자 카드의 수록 시리즈·총기 그룹 수도 함께 확인한다.

소스 폴더에는 `index.html`, `catalog.js`, `catalogue-search.js`, `weapon-specs.js`, `weapon-detail.js`, `main.js`, `mygun2.css`, `images/`가 있다. `public/`는 빌드 산출물이며 직접 수정하지 않는다. 신규 가이드 경로는 기존 가이드 카탈로그 수집에 따라 검색·사이트맵에 포함된다.

관련 검사: `node --test tests/unit/mygun2-catalogue.test.js tests/unit/mygun2-weapon-detail.test.js`, `npx playwright test --config tests/e2e/playwright.mygun2.config.js`. 브라우저 검사에서는 외부 서비스·API를 차단하고 검색/필터/빈 결과, 비교 선택 유지/상한, 레벨 예외/세트, 이미지 실패/상세, PC·모바일의 두 테마를 확인한다. 151개 이미지 항목 전부 기본 스펙이 연결되며, 예비탄약은 모두 무한으로 표시한다.

## 첫 버전 검증 상태

- 전체 단위 1,180개 통과. 관련 브라우저 7개 통과.
- 빌드·산출물 468개 및 JS/CSS 미러 215개·소스 기준·공개 산출물 직접 수정 정책 검사 통과.
- PC 다크·모바일 라이트 스크린샷에서 실제 총기 이미지와 줄바꿈을 확인했다.
- 운영자 검토 후 2026-11-05 커밋·푸시·운영 반영을 승인받았다. 공개 경로는 `/guides/mygun2/`이며, 가이드 허브·사이트 검색·사이트맵을 함께 반영한다. 배포 성공 및 운영 화면 검증은 로컬 테스트와 별도로 확인한다.
