# 마이건2 기본 성능 수치 점검 · 2026-11-06

## 점검 범위

- 기본형 38개: [넥슨 주무기 가이드](https://guide.sa.nexon.com/guide/39) 16종과 사용자 제공 인게임 캡처 22종의 대미지·연사력·명중률·총기반동·장전 수를 대조했다.
- 공식 가이드는 이번 점검에서 원문 HTML을 새로 받아 제목별 네 개 `--value` 값·장탄수·분류·출처 앵커를 확인했다. 원문 수정일은 2026-08-27이다.
- 인게임 값은 대화에 제공된 캡처를 읽어 대조했고, 원본 PNG 22개의 SHA-256도 확인했다. 중복 자료가 있는 총기는 운영자가 새로 제공한 정정 캡처를 우선했다.
- 149개 총기 이미지 항목에 기본형 연결 누락이 없고, 모든 마이건2 예비탄약이 무한으로 표시되는지 확인했다. 장전 수와 진화 추가 장탄수는 구분한다.
- 실제 게임에서 38종을 모두 새로 조회한 점검은 아니다. 오래된 캡처 이후 게임 패치·모드별 차이가 생겼는지는 이 자료만으로 확정할 수 없다.
