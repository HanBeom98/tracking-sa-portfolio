## 동작과 비용 경계

- 매치 목록은 공급자가 제공하는 최근 최대 1,000경기 범위 안에서 재사용한다. 날짜를 바꾸어도 조회 범위를 확장하지 않는다. 활동은 한국 시간 기준 오늘을 제외한 직전 30일을 집계하고, 날짜별 상세는 선택 시 조회한다.
- 완료 날짜 30개·5개 유형의 모의 목록 요청 수는 최대 150회에서 5회로 줄었다. **목록 요청 수**의 비교이며 전체 API 호출·실사용 속도·요금 절감률 측정은 아니다.
- 조회 실패를 0딜·0헤드샷·0경기로 확정하지 않고, 이전 구간이 없을 때 현재 구간으로 대체하지 않는다. 개별 최근 경기 상세 실패 시 목록 요약을 사용하는 기존 대체 동작은 유지한다.
- 리그 경기 유형·MMR/HSR 정산·OUID 기준 임시 닉네임 발견과 복귀를 보존했다. UI 데이터 입력 이름을 바꾼 것이며 도메인의 `matches` 배열을 일괄 변경하지 않았다.
- 리플레이 초기화·선수/파일 변경·종료 후 늦은 응답이나 이미지 생성이 새 결과/버튼을 덮지 못하게 한다. BFCache의 `persisted: true`는 세션을 유지한다. 일반 무료 화면은 로컬 복기·구매 테스트 모듈을 로딩하지 않는다.
- Discord v2는 과거 명령·버튼·모달에 비공개 안내를 반환한다. 구형 어댑터는 기존 원복 절차를 위해 보존했다. 사용 중인 인증/경로 호환 파일을 이름만 보고 삭제하지 않았다.
- 새 DB 저장·유료 의존성·모니터링·유료 AI 호출·실제 구매 활성화는 추가하지 않았다. 기존 서비스의 모든 상황에서 비용이 0원이라는 보장은 아니다.
