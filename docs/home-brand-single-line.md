# 홈 브랜드 디자인과 한 선 리플레이 그래프

2026-10-29. 기존 홈 첨부 연결에 게임 브랜드 시안을 적용하고 상황 우세 지수의 표시를 정리한 기록이다. 운영 반영 여부는 배포 커밋과 `build.txt`로 별도 확인한다. [문서 목차](README.md) · [기존 파일 연결](home-replay-entry.md) · [재생 기준](replay-playback.md).

## 홈

- 소개 상단은 TRACKING SA 워드마크와 SUDDEN ATTACK 보조 표기로 구성한다. 기존 색상 변수를 사용하고 외부 폰트·이미지·애니메이션 없이 글자·사선·배지로 표현한다.

- 제목·파랑/청록 포인트·은은한 배경과 결과 미리보기로 표현 계층을 정리했다. 기존 공통 헤더/푸터·GET 검색·최근 검색·공지·방송·하단 도구는 유지한다.
- PC에서는 제목/검색과 리플레이 미리보기를 나란히 두고 JSON 첨부를 그 아래에 둔다. 모바일에서는 검색→첨부→공지/미리보기 순서로 바꾸어 파일 선택이 첫 화면에서 보이도록 한다.
- 미리보기는 기존 첫 가상 단일 샘플의 실제 검증된 6개 라운드 경로와 1:5 점수를 사용한다. 실제 사용자 경기나 유료 AI 결과로 표시하지 않는다. 단위 검사에서 현재 샘플과 경로 일치를 확인한다.
- 두 샘플 버튼은 같은 홈 연결 컨트롤러로 기존 샘플을 연다. 마크업의 정적 SVG 외 브라우저 모듈·이미지·외부 폰트·API·DB/AI 호출은 추가하지 않는다. 첨부할 때만 분석 엔진을 불러오는 정책을 유지한다.
- 샘플이 변경되면 `node scripts/update-home-replay-preview.mjs --write` 후 빌드한다. 옵션 없이 실행하면 갱신 필요 여부만 검사한다. 완결된 R 유형·전체 라운드 검증 여부를 확인하며, 경로·점수·단위·접근성 설명도 함께 생성한다. 생성 코드는 개발 시점에만 실행한다.

## 한 개의 지수선

기존 A팀 `indexA`와 B팀 `100 - indexA` 두 곡선에서 **A팀 지수 한 개의 곡선**으로 바꾼다. 처음에는 표현만 변경했으며, 이후 사용자에게 확인한 전후반 규칙으로 R 유형의 계산을 경기 승리 추정치로 확장했다. [계산 기준](replay-playback.md#경기-승리-추정치와-규칙)을 따른다.

- 0~100 축과 50 균형선을 유지한다. 50 위는 A팀 우세(청록), 아래는 B팀 우세(빨강/분홍)다. 설명·범례·현재 상태 문구로 색 이외의 구분도 제공한다.
- 현재 시점 마커도 하나다. A/B 숫자와 점수·공수·선수/사건 정보는 그대로 제공한다.
- 옅은 전체 경로와 현재 시점까지의 진한 경로는 같은 좌표를 겹쳐 보여 주는 하나의 지수선이다. 미래의 반대편 지수를 새로 계산하거나 두 번째 곡선으로 표시하지 않는다.
- 사건 시각의 계단형 변화와 라운드별 경로 분리를 유지한다. 검증이 보류된 라운드를 연결하거나 값으로 메우지 않는다. 이탈·재입장 복원과 장면/선수 필터는 기존 기준을 유지한다.
- R 유형의 한 선은 전후반·조기 종료·골든라운드를 반영한 경기 승리 추정치이며 실측 승률이 아니다. 다른 유형은 상황 우세 지수를 유지한다. 홈 가상 샘플은 R 유형의 완결된 1:5 경기로 수정했고, 전반 3:1에서 공수교대한다. 홈 정적 SVG와 샘플 체험이 같은 승리 추정치를 사용한다.
- ‘이 시점 이미지’의 정사각형 PNG도 같은 한 선·50 기준·현재 마커를 사용한다. 보류 음영·현재 시점 설명을 유지하고 기본 요약 이미지 크기는 바꾸지 않는다.
