# 리플레이 상황 분석 기준

공식 리플레이 JSON의 사건 기록을 재구성하는 규칙 기반 분석이다. 생성형 AI, 유료 API, 구독·결제·사용량 차감 기능은 연결하지 않았다. 리플레이 파일과 계산 결과를 서버에 저장하지 않는다. 기존 경기 유형 조회·전력 비교의 OpenAPI 동작은 유지한다.

## 표시하는 내용

| 항목 | 판단 기준 | 해석 범위 |
| --- | --- | --- |
| 첫 처치·첫 사망 | 해당 라운드의 가장 이른 처치 사건 시각에 선택한 선수가 포함되는지 | 동시 사건이면 먼저 일어난 선수를 임의로 정하지 않는다. |
| 사망 직전 생존 인원 | 라운드별 참가자에서 이전 시각에 사망한 선수를 제외한 아군·상대 수 | 선택한 선수 본인을 포함한다. 초기 인원을 5대5로 고정하지 않는다. |
| 교환킬 후보 | 상대가 팀원을 처치한 뒤, 살아 있는 아군이 같은 상대를 0초 초과~5초 이내에 처치 | 가장 최근의 해당 상대 처치를 기준으로 한다. 같은 시각의 팀원 사망은 함께 보관한다. 실제 시야·거리·의도적인 커버를 입증하지 않는다. |
| 혼자 남은 상황 | 선택한 선수가 살아 있고 아군 1명·상대 2명 이상이 처음 되는 시점 | 상대 수와 최종 라운드 결과를 기록한다. 패배 책임이나 실력을 단정하지 않는다. |
| 복기 우선순위 | 기존 최고 라운드를 유지하고, 첫 사망 또는 다수 상대와 혼자 남은 상황을 복기 후보로 사용 | 자동 평가는 참고 자료다. |

시간은 JSON의 `timeStamp / 10`초다. 같은 시각의 모든 사망은 공통의 직전 인원에서 계산하고 한꺼번에 반영한다. 이 그룹 안에서 일시적인 1대다수 상황이나 0초 교환킬을 만들지 않는다. 사망 후 발생하는 투척물 등의 처치는 원래 기록을 유지하되, 살아 있는 팀원의 교환킬로 세지 않는다.

## 검증된 라운드와 판정 보류

`replay-context.js`는 참가자, 요약 K/D, 상태와 처치 사건이 서로 맞는 라운드만 `complete`로 처리한다. 공격·수비 전환은 경기 전체 팀 정보보다 라운드별 참가자 팀을 따른다.

다음은 `partial`로 처리하며, 생존 인원·교환킬·혼자 남은 상황을 계산하지 않는다. 기존 처치·사망 타임라인은 계속 볼 수 있다.

- 참가자 중복·누락·미지원 팀, 요약 K/D 누락 또는 사건과 불일치
- 중도 입장·퇴장·재접속 표시, 사망 후 다시 생존하는 상태
- 알 수 없는 참가자, 팀 불일치·팀킬·중복 사망, 범위 밖 또는 누락된 사건 시각
- `eventType=0` 이외의 처치 코드, `state=1/2` 이외의 상태 코드
- 초기 생존 상태 누락, 사망 상태와 사건 시각 불일치(1틱 초과)
- 첫 상태가 첫 처치보다 늦거나 0.5초보다 늦게 시작하는 기록
- 경기 시간 또는 라운드 결과·공격 팀을 확인할 수 없는 기록

초기 0.5초 기준은 제공된 실제 파일의 모든 참가자가 0.5초부터 기록된 것을 바탕으로 한 보수적인 지원 범위다. 다른 정상 파일도 이 조건을 벗어나면 보류될 수 있으며, 추가 표본 검증 후 넓혀야 한다. 폭탄 코드의 정확한 의미, 벽·시야·음성 정보, 플레이 의도는 이 분석에서 추정하지 않는다.

화면에는 `상황 기록 확인: N/M개 라운드`를 표시한다. 일부 보류 시 상황 설명에도 해당 표본 범위를 붙인다. 보류한 라운드는 상황이 없었던 라운드(0건)로 해석하지 않는다.

## 검증

- 합성 데이터 단위 테스트: 동시 사망, 5초 경계, 최근 팀원 사망 선택, 사망 후 처치, 팀 전환, 비대칭 초기 인원, 누락·변동 기록의 판정 보류를 확인한다.
- 로컬 브라우저 테스트: 390px·1280px에서 기존 카드·복기 이동·사망 상세·파일 교체·판정 보류를 확인한다. 외부 서비스를 차단하며, 오래된 합성 경기로 기존 전력 비교를 제외하고 추가 `/api/` 요청이 없는지 검사한다.
- 실제 파일 회귀 확인: 팰리스-심플 9라운드·10명, 61개 처치 사건을 로컬에서 분석했다. 각 선수의 9개 라운드가 검증되며 경기 전체 교환킬 후보 7건, 혼자 남은 상황 9건을 확인했다. 제공 순서의 세 번째 선수는 4·9라운드 첫 사망, 1라운드 0.6초 교환킬 후보, 5라운드 49.3초부터 1대3 상황이었다.

실제 파일과 닉네임·계정 식별자는 저장소에 포함하지 않는다. 위 수치는 이 파일의 회귀 검증 결과이며 일반적인 분석 정확도나 AI 성능 측정치는 아니다.
