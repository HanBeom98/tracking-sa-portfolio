# 홈에서 전적 검색·리플레이 파일 분석 시작

2026-10-29. 홈과 리플레이의 연결을 구현·로컬 검증한 기록이다. 운영 반영은 커밋·배포 이후 별도로 확인한다. [문서 목차](README.md) · [리플레이 폴리싱](replay-polishing.md).

## 사용자 흐름

- 홈의 큰 반복 설명을 줄이고 닉네임 검색과 JSON 첨부를 구분한다. 후속 [브랜드 디자인](home-brand-single-line.md)에서 PC는 검색/미리보기와 하단 첨부, 모바일은 검색→첨부→미리보기로 정리했다. 닉네임 검색과 파일 분석의 입력을 구별한다.
- 전적 검색은 기존 `/stats/sudden-attack/?n=...` GET 폼을 유지한다. 기존 최근 검색·공지·SOOP 방송과 사업자 푸터를 유지한다. 분석 도구 안내는 라이브 앞에 둔다.
- JSON 1개는 한 경기 선수 선택으로, 2~5개는 같은 선수 ID 비교로 연결한다. 파일 선택/끌어놓기와 샘플 체험을 제공한다. 6개 이상·중복 경기·잘못된 JSON 등은 기존 검증 경로에서 설명한다.
- 파일이 없을 때는 첨부 영역 안에서 ‘파일 받는 방법’을 펼쳐 공식 병영수첩 링크와 다운로드 순서를 확인한다. 자세한 기존 가이드와 독립 분석실 링크도 유지한다.
- 파일을 선택한 뒤에는 홈을 숨기고 같은 문서의 분석 작업 화면을 연다. 선수를 선택하고 기존 분석 버튼으로 결과를 확인한다. 다시 파일을 선택하도록 페이지 간 전달을 요구하지 않는다.
- 홈 복귀는 재생을 멈추고 홈 스타일을 복원한다. 브라우저 뒤로/앞으로는 같은 페이지 안에 보존된 작업 화면을 복원한다. 결과의 핵심/재생/세부/라운드 앵커도 분석 화면을 유지한다.

## 구현과 데이터 범위

`src/domains/home/replay-entry.js`는 작은 홈 연결 모듈이다. 초기 홈에서는 리플레이 문서·스타일·분석 엔진·샘플·비교 모듈을 불러오지 않는다. 파일 첨부·샘플·분석실 열기를 선택했을 때만 같은 출처의 정적 분석실 HTML을 가져온다. 기존 `main.replay-shell`만 재사용하므로 분석 마크업을 홈에 별도로 복사하거나 공통 헤더·푸터·설정 스크립트를 다시 실행하지 않는다.

분석실의 버전이 붙은 CSS를 읽고, 기존 모듈을 지연 import한다. 기존 `main.js`에 파일 진입/샘플/재생 정지 인터페이스를 노출했으며 계산 코드는 바꾸지 않는다. 1개는 기존 `load`, 여러 개는 기존 지연 비교 컨트롤러의 `loadFiles`를 사용한다. 선택 파일명은 텍스트로 표시한다.

File 객체는 현재 문서 메모리에서만 넘긴다. 원본 JSON·분석 결과를 서버/DB/Storage/브라우저 영구 저장소에 추가 저장하지 않는다. 따라서 새로고침하거나 문서를 떠나면 파일을 다시 선택해야 한다. 이것은 파일을 잃어버리는 버그를 숨긴 복구 약속이 아니다.

한 경기의 기존 경기 유형·전력 조회에는 경기 ID·닉네임을 사용하는 NEXON API 경로가 있다. 기능 전체가 네트워크 없이 동작한다는 설명은 하지 않는다. 이번 연결은 정적 자산 로딩 외 신규 API·DB·AI·분석 이벤트를 추가하지 않으며, 기존 공지 읽기·방송 조회까지 없애는 변경도 아니다.

정적 UI/스타일 로딩 실패는 홈의 오류 안내와 독립 분석실 링크를 남긴다. 준비 중 선택한 파일이 바뀌면 마지막 선택만 적용하고 정적 준비 요청은 공유한다. 성공한 작업 화면은 한 번만 마운트한다.

## 검증

로컬 고정 픽스처만 사용하고 외부 Firebase·광고·분석·실제 API는 차단한다. 기존 홈 공지 읽기의 Firestore `POST runQuery`는 쓰기/파일 업로드와 구분한다.

`home-replay-entry.spec.js` 14개는 다음을 확인한다. 후속 브랜드 미리보기의 두 샘플 버튼도 같은 분석실로 연결한다.

- 390/1280px × 밝은/어두운 테마: 초기 첨부 영역 노출·가로 넘침 없음·분석 자산 초기 요청 없음.
- 샘플 고지·결과/재생·앵커 이동·단일 헤더/푸터·홈 복귀 시 일시정지.
- JSON 한 번 선택으로 기존 분석·보고서 도달, 같은 파일 재선택, 파일명 표시.
- 두 경기의 같은 ID/다른 닉네임 비교, 다중→단일 전환과 끌어놓기.
- 확장자·2MB·JSON 파싱·지원 구조·최대 5개·중복 경기 검증.
- 정적 문서 실패 후 재시도·직접 진입 대안·느린 로딩 중 마지막 선택 우선.
- GET 검색 경로 유지, 브라우저 뒤로/앞으로, 영구 저장 없음과 새로고침 후 재선택.

홈 연결을 실제 구매·유료 AI·토스 심사 통과로 해석하지 않는다. 상품·가격·환불·TEST 결제·사업자 정보는 변경하지 않는다.

### 파일 선택 상태 표시

첨부 영역은 확인 중·선택 완료·읽기 오류를 구분한다. JSON 구조와 플레이어 목록 확인이 끝난 파일만 체크 표시와 초록색 실선 테두리로 표시하고, 파일명을 첨부 영역 안에 남긴다. 긴 이름은 줄바꿈하고 문자열로만 표시한다. 선택 완료 후 플레이어 선택·분석 버튼 순서를 안내하며, 선택 파일과 무관한 전력 조회 진행이 완료 표시를 덮어쓰지 않는다. 초기화하면 빈 상태로 돌아오고 새 파일 확인 중·오류에서는 이전 완료 표시를 제거한다. 홈에서 넘긴 파일·직접 첨부·샘플 모두 같은 표시를 사용한다.
