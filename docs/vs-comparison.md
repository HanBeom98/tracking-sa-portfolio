# VS 비교 지표와 선택 구간

2026-11-07 유지보수 체크리스트 5번 구현 기준.

## 공개 전적

공개 VS는 **K/D·승률·경기당 킬**을 각각 한 번 비교한다. 기존 종합 K/D와 최근 K/D는 같은 `kdPercent`를 사용해 한 지표가 두 표를 얻었으므로 중복 행을 제거했다. 실제로 제공되지 않는 평생 K/D를 만들지 않는다.

| 지표 | 계산 기준 | 차이 단위 |
| --- | --- | --- |
| K/D | 선택 경기의 총 킬 ÷ (총 킬+총 데스) × 100 | %p |
| 승률 | 승리 경기 수 ÷ 집계 경기 수 × 100, 무승부도 분모에 포함 | %p |
| 경기당 킬 | 선택 경기의 총 킬 ÷ 집계 경기 수 | 킬 |

선택 구간은 각자의 전체 최근 1~20번째 또는 이전 21~40번째 경기다. 같은 순서 구간을 선택하며 두 사람의 실제 경기 수·플레이 날짜·매치 구성이 같다는 뜻은 아니다. 특정 유형 탭에서 VS를 열어도 공개 VS 자체의 범위는 전체이며 화면에 범위를 표시한다. 경기 수와 표본 부족 안내를 함께 표시한다.

## 데이터 전달과 빈 값

카드에 전달하는 경기 구간·비교표·레이더는 공통 `getVsComparisonData`로 선택한다. 표와 레이더가 최상위 최신 `profile.stats`를 잘못 읽지 않는다. 이전 구간이 없는 사용자를 다른 사용자의 이전 구간과 비교할 때 현재 구간으로 대체하지 않는다.

프로필 상단의 공식 제공 요약·티어는 별도의 공식 정보다. 자체 선택 구간 수치를 공식 최근 수치인 것처럼 바꾸지 않으며 화면·사용자 가이드에서 둘을 구분한다.

경기 표본 또는 숫자가 없는 값은 — 로 표시하고 우세 수에 포함하지 않는다. 실제 경기에서 확인된 0킬·0승은 0으로 유지하되, 킬과 데스가 모두 0이면 K/D의 분모가 없으므로 비교에서 제외한다. 양쪽 모두 비교 가능한 항목이 없으면 비교 보류와 레이더 표본 부족을 표시한다.

우세 항목 수는 표시된 값의 단순 비교다. K/D·킬·승률은 서로 영향을 받으며 독립적인 투표나 승리 확률이 아니다. 예를 들어 K/D만 A, 승률만 B가 높고 경기당 킬이 같으면 우세 수는 1:1이다.

## 리그

리그 VS도 선택한 이번/지난 시즌을 표와 레이더에 전달한다. MMR·HSR 비교는 유지하며 비회원의 기본 점수를 실제 리그 점수로 비교하지 않는다. 리그 정산·경기 유형·닉네임 이력은 변경하지 않는다. 새 API 호출·DB·유료 의존성을 추가하지 않는다.

## 검증

단위 검사로 중복 K/D의 잘못된 2:1 우세 재현, %p/킬 단위, 빈 값·실제 0값 구분, 리그 점수 보존, 이전 구간 누락 시 대체 금지, 공개 화면의 카드/표 전달과 문자 이스케이프를 검증한다. 브라우저에서는 PC·모바일 양쪽 테마에서 최근/이전 구간의 표와 실제 레이더 데이터, 표본 수, 이전 구간 누락 시 보류를 확인한다. 외부 API·운영 DB는 모의로 대체한다.
