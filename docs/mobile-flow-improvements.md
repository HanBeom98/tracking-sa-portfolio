# 모바일 결과 배치와 공유 상태 개선

작성일: 2026-10-23. 성장 8번 **구현·로컬 검증** 기록이다. 운영 배포는 [9번 배포·확인 기록](mobile-flow-release.md)에서 완료했다. 실제 iPhone Safari/Android 검증은 미확인이다. [7번 점검](mobile-flow-audit.md)에서 확인한 문제를 근거로 수정했다.

## 사용자 화면의 변화

- 공유·사진 편집은 기본 접힌 영역에서 한 번 눌러 펼친다. 이미지/링크 공유·사진 선택·위치/확대 조정·3D 카드 기능을 유지한다. 사용자가 펼친 상태는 같은 문서의 재검색에서 임의로 접지 않는다.
- 공개 전적의 핵심 KPI와 최근 구간 변화 설명을 상세 프로필보다 먼저 배치했다. 계산식·표본 조건·최근/이전 20경기·31일 활동·VS 비교는 유지한다. 리그 계산/위장 닉네임·OUID·0승 0패 정책은 변경하지 않았다.
- 공개 페이지 즐겨찾기 칩의 이름/VS/삭제 버튼은 최소 44×44 CSS px로 넓혔다. 긴 이름은 말줄임으로 처리한다.
- VS 모달에 dialog 이름·설명·aria-modal을 추가했다. 입력 자동 포커스, Tab/Shift+Tab 순환, Escape 닫기와 열기 버튼 포커스 복귀를 확인한다.
- 화면 폭이 바뀌면 공유하기/이미지 복사 이름을 실제 분기에 맞춘다. 취소는 취소 안내, PNG는 저장 요청 안내로 표현하며 저장 완료라고 단정하지 않는다.

## 공유 대기와 늦은 응답

| 단계 | 처리 | 측정/한계 |
| --- | --- | --- |
| 카드 생성 | 폰트는 최대 2초 대기 후 현재 폰트 사용, 장식 이미지는 최대 6초 후 기본 표시 사용, canvas Blob은 최대 5초. 컨트롤러 생성 작업 전체는 15초 상한 | 생성 실패 시 한 번 실패 종료. 같은 이미지를 자동 재생성/재요청하지 않음. 장식 이미지가 빠질 수 있음 |
| 기기 공유 창 | 완료하거나 취소해 달라는 안내, 사용자 응답을 기다림 | 강제 시간 초과·자동 취소 없음. resolve/cancel/reject의 실제 결과로 처리 |
| 이미지 클립보드 | 복사 결과 확인 중 안내. 8초 대기 시 PNG 저장/결과 링크 경로 안내 | 안내만으로 성공/실패로 기록하지 않음. 실제 브라우저 쓰기는 취소할 수 있다고 가정하지 않음 |
| 대기 중 PNG 선택 | 이미 생성한 Blob으로 저장 요청. 원래 시도의 png_download/download_requested를 한 번 기록 | 원래 브라우저 쓰기가 끝날 때까지 이미지 버튼은 비활성으로 두어 중복 쓰기 방지. 결과 링크는 사용 가능 |
| 늦은 복사 응답 | PNG 선택 뒤 완료/실패가 도착해도 추가 finish·자동 다운로드·안내 덮어쓰기 없음 | 원래 API가 실제로 클립보드에 쓸 가능성은 남음. 강제 취소했다고 표현하지 않음 |
| 결과/구간 전환 | 수락한 모델/사진 정보를 사용하고 새 결과에 이전 성공 안내를 붙이지 않음. 이전 작업 대기/종료 안내를 구분 | 진행 중 이미지 작업을 중복 실행하지 않으며 현재 결과의 링크 복사는 가능 |

이미지 버튼과 별도로 링크 복사를 수행하면 각각 실제 작업의 종료를 기록한다. 늦은 이미지 응답은 더 최근의 링크 안내를 덮어쓰지 않는다. 측정기 자체의 실패는 기존처럼 기능과 격리한다. 새 이벤트 이름·식별자·GA 맞춤 정의를 추가하지 않았다.

## 같은 화면의 배치 비교

로컬 Chromium·동일한 합성 20경기·기본 접힌 공유 영역 기준. 밝은/어두운 테마에서 거리는 같았다. CSS px의 배치 값이며 실제 사용자 속도·스크롤 횟수·이탈률·전환 개선율이 아니다.

| 화면 폭 | 결과 시작→첫 승률 카드 변경 전 | 변경 후 | 거리 감소 |
| --- | ---: | ---: | ---: |
| 390 | 2,326 | 622 | 1,704 (73.3%) |
| 402 | 2,314 | 622 | 1,692 (73.1%) |
| 1280 | 1,046 | 517 | 529 (50.6%) |

390/402/1280px × 두 테마, 긴 합성 이름·0경기·조회 오류·VS·사진 편집 등 동일한 19개 관찰을 다시 수행했다. 관찰 pageerror와 문서 가로 넘침은 없었다. 이는 모든 환경에 결함이 없다는 보장이 아니다. 실제 검색 데이터·운영 지표는 포함하지 않는다.

## 검증과 운영 경계

- 새 단위 검사는 지연된 resolve/reject·명시적 PNG 한 번·중복 클릭·새 결과/링크 안내 보호·생성 상한을 확인한다. 전체 단위 검사 576개, Python 33개를 통과했다.
- 로컬 브라우저 회귀 29개에서 기존 검색/캐시/VS/공유·오류·소스 분리와 새 UI를 검증한다. 폰트와 장식 이미지 응답을 보류하는 fixture도 사용한다. 외부 요청은 차단하며 실제 clipboard/share/download를 실행하지 않는다.
- 빌드, source/public 146개, 필수 산출물 243개, public 편집 정책과 DDD 계층 검사를 확인한다. 변경 전후 PNG와 점검 JSON은 로컬 산출물로 보관한다.
- 추가 분석 저장소·BigQuery·유료 도구·새 API 호출·자동 재시도·결제 설정 변경은 없다. 카드 생성 실패의 자동 재생성을 제거해 중복 외부 이미지 조회도 줄였다.
- 운영 첫 이미지 복사 미종료의 근본 원인은 여전히 미확정이다. 그와 유사한 대기 상태의 안내/대체 경로를 개선한 것이며 실기기 해결을 입증한 것은 아니다.
- 6번의 처리된 일반 이용 기준 표본은 대기 중이다. 새 배치에서는 같은 summary_view 조건도 더 쉽게 충족될 수 있으므로 변경 전후 기간을 구분하고 노출을 이해도/전환 효과로 단정하지 않는다.
- 이번 기록은 8번 구현 범위다. [9번 배포·운영 확인](mobile-flow-release.md)에 코드 버전·CI·파일 해시·진입 화면과 실기기 미확인 항목을 기록했다.
