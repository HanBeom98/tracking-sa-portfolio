# 리플레이 시작·결과 화면 폴리싱

2026-10-29. 사용자 동선 점검의 P1·P2를 구현·로컬 검증한 기록이다. 운영 배포 확인과 구분한다. [문서 목차](README.md) · [현재 상태](current-status.md).

## 시작 화면

- 목적을 ‘병영수첩 JSON으로 경기 흐름과 주요 장면 확인’으로 짧게 설명한다. 큰 장식·반복 기능 소개·별도 증명 카드를 제거했다.
- 한 경기/여러 경기 탭은 기존 ID·ARIA 상태·화살표/Home/End 이동·선택 보존을 유지하면서 높이를 줄였다.
- 파일 선택 상자의 크기·레이블·강조를 정리하고, 기존 사용 가이드 링크를 입력 옆으로 옮겼다. 두 가상 샘플 버튼은 항상 사용할 수 있는 보조 행동으로 유지한다.
- 파일의 기기 내 처리와 추가 전력 조회의 데이터 범위를 설명하는 기존 안내·오류·검증 제한은 유지한다.

## 결과 화면

- 공식 경기 총계와 기존 계산 수치는 바꾸지 않는다. 모바일은 4개 수치를 2열로 표시하고 결과 제목·버튼·여백을 줄였다.
- 상단 바로가기는 **핵심 장면 / 경기 재생 / 세부 기록** 3개로 정리했다. 기존 핵심 장면을 수치 다음에 배치하고, 재생·경기 흐름이 이어진다.
- 기록 진단·추가 전력·무료 기록 해설 예시·생존·투척·라운드·상세 항목은 세부 기록 영역으로 모았다. 하위 바로가기와 기존 목적지 ID는 유지한다.
- 기존 ‘분석 카드 공유’ 버튼의 표시 이름은 **이미지 공유**로 줄였다. PNG 생성·공유·다운로드 동작과 보고서/PDF는 유지한다.
- 새로운 결과 탭이나 숨김 처리를 추가하지 않는다. DOM 안의 기존 패널을 재배치해 전력 갱신·재생 위치/필터·장면 이동·저장 결과 근거 연결이 같은 요소를 사용하도록 한다.

## 관찰한 배치 수치

같은 브라우저의 390×844·어두운 테마·첫 가상 단일 샘플 기준으로 측정했다.

| 항목 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 보이는 파일 선택 상자 시작 y | 1,407px | 544px |
| 파일 선택 상자 끝 y | 1,637px | 662px |
| 결과 시작부터 핵심 장면 시작까지 | 2,707px | 541px |

처음 점검 때 기록한 1,521px은 상자 안의 숨겨진 파일 input 요소 좌표였다. 위 표는 변경 전·후 모두 **보이는 `#replayDropzone` 상자**를 다시 측정한 값으로 혼용하지 않는다. CSS 배치의 한 관측이며 FCP/LCP·실사용 전환·이해도 개선 수치가 아니다. 브라우저·화면·문구·경기에 따라 값은 달라진다.

## 보존 범위와 검증

- 변경은 리플레이 원본 HTML/CSS·결과 표시 템플릿과 가이드 문구에 한정한다. 홈·공통 헤더/스타일·사업자 푸터·상품/약관·결제/주문·API/AI·데이터 계약은 변경하지 않는다.
- 원본 JSON·선수 ID·닉네임 처리·계산 공식·상황 검증·재접속 복원·추가 조회/캐시·비동기 결과 무효화 정책을 유지한다. 모든 지표를 새로 ‘검증 라운드 기준’으로 재명명하지 않는다.
- 새 브라우저 모듈·외부 라이브러리·API·AI 호출·DB 저장·분석 이벤트를 추가하지 않는다. 기존 별도 전력 조회까지 없애는 작업은 아니다.
- 반응형 검사는 390×844/1280×720×밝은/어두운 테마에서 시작 입력 노출, 비교 입력, 샘플, 수치 배치, 핵심/재생/세부 순서, 재생 상태 보존, 라운드 필터·PDF·가로 넘침·API 0건을 확인한다.
- 별도 부분 검증 사례로 기존 총계·검증 보류 고지와 초기화를 확인한다. 기본 CI에 포함하고 기존 재생·비교·전력 지연·출력 회귀 검사도 유지한다.

홈과 전적 검색 폴리싱은 P3·P4 후보로 남기며 이 변경에 포함하지 않는다.

| 로컬 검사 | 통과 |

| 기본 브라우저(새 배치 5개 포함) | 90개 |

원본/산출물·필수 파일·브라우저 연결/계층·문서 상대 링크 검사도 통과했다. 운영 인증·실제 구매·유료 AI를 이 검증으로 확인한 것은 아니다.

## 결과 제목 카드의 맵 배경 — 2026-10-30

리플레이 결과 제목 카드에 해당 맵의 기존 로컬 이미지를 배경으로 표시한다. 전적 검색에서 사용하던 `getMapImagePath` 매칭을 재사용해 `이탈리아-폭파` 같은 이름에도 대응하며, JSON 문자열을 이미지 URL로 직접 사용하지 않는다. 어두운 그라데이션과 밝은 글자를 함께 적용해 두 테마에서 제목·경기 결과·공유/PDF 버튼을 읽을 수 있게 한다.

홈 안의 한 경기 분석과 별도 분석실에 같은 결과 템플릿이 적용된다. 등록되지 않은 맵은 기존 단색 카드를 유지하고, 이미지 요청에 실패해도 그라데이션·제목·버튼은 남는다. 이미지 다운로드 외에 새 API·AI·DB 호출은 추가하지 않는다. 공유 PNG와 PDF 보고서의 배경은 이 변경 범위에 포함하지 않는다.

관련 단위 검사 529개와 결과 화면 브라우저 검사 12개를 통과했다. 브라우저 검사는 390/1280px·밝은/어두운 테마, 홈 진입, 다른 파일로 변경할 때 배경 초기화, 이미지 요청 실패, PDF와 초기화 버튼 동작을 포함한다. 구현·로컬 검증과 운영 배포는 별도로 확인한다.

## 이미지 공유·복사 보완 — 2026-10-30

기존 리플레이 공유 버튼은 기기 공유창 또는 파일 다운로드로 바로 연결돼, 이미지 클립보드 복사를 직접 선택할 수 없었다. 운영 확인에서 기기 공유 실패도 일반적인 카드 생성 실패로 표시되는 것을 재현했다. 이제 준비한 PNG를 미리보기로 보여주고 **이미지 복사 / PNG 저장 / 지원 기기의 기기로 공유**를 각각 선택한다. 요약 카드와 현재 재생 장면 이미지에 같은 흐름을 적용한다.

복사는 이미지 생성이 끝난 뒤 사용자가 누른 버튼 안에서 `ClipboardItem({'image/png': blob})`으로 시작한다. 클립보드 쓰기가 실제 성공했을 때만 복사 완료를 표시한다. 복사 권한 거부·미지원·응답 지연·기기 공유 실패 시 PNG 저장을 선택할 수 있으며, 공유 취소를 자동 다운로드로 바꾸지는 않는다. 다른 파일·선수 선택이나 홈 작업 화면 종료 시 이전 미리보기를 닫고 이미지 URL을 해제한다.

로컬 브라우저에서 실제 PNG 복사 후 Ctrl+V로 이미지 붙여넣기 이벤트까지 확인했다. 디스코드·카카오톡으로 실제 메시지를 전송하는 검사는 수행하지 않는다. 파일·이미지 생성은 기기 안에서 처리하며, 새 서버 저장·API·AI 호출은 없다. 기존 PDF 보고서 동작도 회귀 검사에 포함한다.
