- 원본 저장소는 비공개로 유지합니다. 계정 자격증명, 실제 환경 파일, 데이터베이스 내보내기, 실행 로그는 포함하지 않습니다.

- 운영 프로젝트에 Emulator 주소를 쓰지 못하게 하는 테스트는 `production-portfolio-example`을 사용해 기존 거부 조건을 유지합니다.
