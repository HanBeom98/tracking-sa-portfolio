# 리플레이 AI의 로컬 API 연결 준비

2026-10-26 후속 [사실·조언 선택 계약](replay-coaching-facts.md)을 내부 구현·오프라인 검증했다. 기존 키는 이번 작업에서 읽거나 호출하지 않았고, 새 계약의 실제 토큰·생성 시험은 미실행이다. 아래 연결/토큰 기록은 이전 계약의 이력이다.

2026-10-25. 기존에 사용하던 OpenAI API 키를 재사용해 모델 접근 여부를 확인했다. 새 키 발급·추가 충전·자동 충전 설정 변경·운영 배포는 수행하지 않았다. 이후 [소액 실제 품질 시험](replay-coaching-pilot.md)을 완료했으며 결과는 유료 출시 보류다.

## 확인한 범위

| 항목 | 상태 |
| --- | --- |
| 기존 키 | 원본을 보존하고 로컬 전용 설정에 선택적으로 복사 |
| 키 보관 | 프로젝트 루트 `.env.replay-coaching.local`, `OPENAI_API_KEY` 한 항목만 보관 |
| Git 제외 | 루트 파일 경로를 `.gitignore`에 명시하고 실제 제외 여부 확인 |
| 모델 조회 | 공식 `GET /v1/models/gpt-6-luna`에서 HTTP 200 및 일치하는 모델 ID 확인 |
| 계정 결제 화면 | 확인 완료, 결제 설정 변경 없음. 비공개 잔액은 저장소 밖 점검 기록에 보관 |
| 실제 입력 토큰 수 | 선택 선수 1명·9라운드 기준 초기 입력 **1,450토큰**. 필드 설명 보완 후 **1,642토큰** |
| 실제 생성·청구·품질 | 소액 생성 시험 완료, 의미 품질 기준 미달. 실제 청구서 대조는 미실행 |

모델 조회 성공은 해당 키로 모델 정보를 읽을 수 있다는 뜻이다. 생성 권한·잔액·사용 한도·실제 요청 성공·청구 금액까지 확인한 결과가 아니다. 기존 다른 작업의 모델 설정을 리플레이에 그대로 복사하지 않았으며, 리플레이 요청의 모델·단가·상한은 [비용 준비 모듈](replay-coaching-budget.md)이 정한 값을 따른다.

## 키를 읽는 경계

- 로컬 파일에는 키 값만 두고 소스·문서·테스트·로그·보고서·커밋에는 값이나 일부 문자열을 넣지 않는다.
- 이 파일은 배포 패키지의 `cloud-functions/` 밖에 있고, 현재 코드가 자동으로 읽거나 생성 기능을 활성화하지 않는다. 로컬 확인 도구에서 경로를 명시적으로 읽어 `createOpenAITokenCounter`에 전달해야 한다.
- 브라우저에 키를 전달하지 않는다. 향후 운영 연결은 별도의 서버 비밀 설정과 권한 검토가 필요하다. 이번에 Cloudflare/Firebase 운영 키를 등록하지 않았다.
- 기존 키의 원래 연결은 별개다. 키를 복사한다고 기존 자동화나 비용 사용이 멈추지 않는다. 기존 작업을 중단할 때는 해당 스케줄·운영 설정도 따로 확인해야 한다.

## 기존 자동화 일시중지

사용자의 승인으로 기존 Threads Worker의 Cron 일정을 제거하고 저장 후 새로고침에서도 일정이 없음을 확인했다. 로컬 배포 설정도 `triggers.crons: []`로 맞춰 다음 배포에서 일정이 복원되지 않도록 했다. 계정·게시글·저장된 문안·데이터베이스와 수동 실행 경로는 보존했다. Cloudflare 안내상 Cron 변경 전파에는 최대 15분이 걸릴 수 있다. 별도의 수동 실행은 자동 일정 중지와 별개다.

잔액은 로그인한 계정 화면에서 읽은 확인 시점 값이다. 실제 토큰 계산은 후속 단계에서 성공했지만 생성 성공·품질·향후 비용까지 보증하지 않는다. 자동 충전·추가 구매·월 한도 등 결제 설정은 변경하지 않았다.
