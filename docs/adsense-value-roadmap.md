# Tracking SA 콘텐츠 가치 개선 체크리스트

목표: 서든어택 공개 전적 API의 숫자를 단순히 표시하는 사이트가 아니라, 플레이어가 검색 전·후 모두 해석과 판단에 도움을 얻는 게임 데이터 서비스로 만든다.

## 0. 기준과 측정

- [x] 공개 전적 검색, 최근 20경기, 시즌 지표, VS 비교, 가이드, 운영·정책 페이지의 현재 상태를 점검한다.
- [x] 비핵심 도구·게임 페이지가 `noindex`이며 사이트맵에서 제외되는지 확인한다.
- [ ] Search Console에서 색인됨 / 제외됨 / 크롤링 오류 URL을 기록한다.
- [ ] Analytics에서 전적 검색 시작률, 검색 후 이탈률, 가이드 이동률을 기준선으로 기록한다.

## 1. 검색 전 사용자 가치

- [ ] 홈과 전적 검색 홈에 `전적 읽기 리포트`를 노출한다.
- [ ] 리포트는 실제 집계 근거가 없는 '오늘의 메타'나 임의 순위를 사용하지 않는다.
- [ ] 각 리포트에 작성일, 근거 데이터 범위, 해석 한계, 관련 가이드를 연결한다.
- [ ] 매주 한 개 이상의 실제 분석 리포트를 발행한다.

## 2. 검색 결과 고유 분석

- [ ] 최근 20경기와 이전 20경기의 승률·K/D·킬·데스 변화를 계산한다.
- [ ] 표본 수, 데이터 갱신 시각, 랭크전 모드 범위를 결과에 명확히 보인다.
- [ ] 상승·하락·변동성 판단에 근거 수치를 함께 표시한다.
- [ ] '실력'을 단정하거나 과장하지 않고, 해석 한계를 표시한다.
- [ ] VS 비교에도 차이의 근거와 표본 한계를 표시한다.

## 3. 원본 콘텐츠 축적

- [x] 실제 익명화 사례를 포함한 분석 칼럼 8개를 발행한다. (8개 발행)
- [ ] 각 글에 작성자, 작성일, 수정일, 출처·검수 기준을 표시한다.
- [ ] 기능 설명만 반복한 얕은 가이드는 통합하거나 보강한다.
- [ ] 업데이트 목록은 승인 관련 문구 대신 사용자에게 의미 있는 변경만 기록한다.

## 4. 색인·광고·신뢰 점검

- [ ] 검색 전 빈 화면, 로딩 화면, 오류 화면에는 광고를 배치하지 않는다.
- [ ] 광고가 검색·메뉴·다운로드 버튼처럼 보이지 않도록 점검한다.
- [ ] 사이트맵에는 완성된 공개 콘텐츠만 남긴다.
- [ ] About, Contact, Privacy, Terms, 데이터 출처와 한계 페이지의 최신성을 확인한다.
- [ ] 모든 내부 링크와 모바일 화면을 점검한다.

## 5. 재신청 전 검증

- [ ] 새 리포트와 분석 기능이 배포된 상태에서 최소 2주간 실제 사용·오류를 확인한다.
- [ ] Search Console의 색인 및 페이지 경험 문제를 다시 확인한다.
- [ ] 광고 코드를 포함한 핵심 페이지의 실제 렌더링과 탐색 흐름을 점검한다.
- [ ] 위 항목이 끝난 뒤에만 AdSense 재심사를 신청한다.
