# 자율 정기 후원

> 과거 검토안: 2026-10-27 운영자의 후원 종료 결정에 따라 사이트의 후원 링크와 안내 페이지는 제거했다. 아래 내용은 당시 설계 기록이며 현재 제공하는 기능이 아니다. 현재 이용권·TEST 상태는 README와 토스 재심사 체크리스트를 따른다. 외부 포스타입 계정·멤버십을 해지했다는 뜻은 아니다.

TrackingSA의 기존 기능은 후원 여부와 관계없이 무료로 제공한다. 서비스 이용권·독점 콘텐츠를 판매하지 않고, 원하는 이용자가 운영과 개발을 응원하는 월 3,000원 정기 후원을 포스타입에서 진행한다.

## 화면과 결제 경로

- 공통 하단의 `운영 후원하기` → `/support/` → [포스타입 TrackingSA 운영 응원](https://www.postype.com/@trackingsa/membership/91906).
- 안내 화면에서 매월 자동 결제되는 금액, 비후원자의 동일한 이용 범위, 포스타입에서의 가입 내역 확인·해지를 설명한다.
- 외부 링크는 새 탭으로 열고 `noopener noreferrer`를 지정한다. 후원 화면을 방문하는 것만으로 포스타입을 요청하지 않는다. 별도 결제 SDK·임베드·구독 상태 조회·서버 API·이벤트 수집은 추가하지 않는다.
- 후원자의 회원 등급이나 권한을 TrackingSA 계정에 연결하지 않는다. 카드번호·결제 비밀번호를 사이트에서 입력받지 않는다.
- 후원 안내 페이지는 검색 색인과 사이트맵에서 제외하고 광고 계정 스크립트를 주입하지 않는다. 다른 페이지의 기존 광고 설정은 유지한다.

소스는 `src/domains/support/index.html`, 공통 진입점은 `src/shared/ui/footer.html`이다. 페이지는 빌드의 도메인 목록과 필수 배포 산출물 목록에 포함한다. 금액이나 외부 주소를 바꿀 때는 실제 공개 플랜과 일치하는지 확인하고 안내 문구도 함께 수정한다. 포스타입은 생성한 플랜 가격을 나중에 변경할 수 없다고 안내하므로 가격 변경 시 플랫폼의 새 플랜 절차를 따른다.

## 운영과 비용

포스타입 채널·플랜 개설과 크리에이터 본인·정산 인증은 서로 다른 단계다. 최초 출금에는 크리에이터 인증과 계좌 등록이 필요하다. 개인 식별정보·정산 서류·계좌번호는 저장소에 넣지 않는다. 사이트 연결 구현만으로 계정 인증·출금·실제 결제 성공을 확인한 것으로 기록하지 않는다.

2026-10-24 확인한 전용 수수료 정책의 멤버십 수수료는 13%와 해당 수수료에 대한 부가세 10%로, 수익 기준 합계 14.3%다. 일부 오래된 멤버십 생성 도움말의 10% 대신 최신 수수료 정책을 따른다. 별도 소득세 등 세무 처리는 이 수수료와 구분한다. 유료 운영자 상품이나 새 서버·분석·DB를 추가하지 않는다.

## 검증

로컬 브라우저 검증은 운영 결제를 하지 않는다. 홈 하단에서 안내 페이지로 이동하고, 월 자동 결제 안내와 실제 대상 주소를 확인한 뒤 외부 페이지를 가짜 응답으로 대체해 새 탭 이동을 검사한다. 게스트가 결제하지 않아도 무료 전적 검색으로 이동하고 검색 입력을 사용할 수 있어야 한다. 390/1280px·밝은/어두운 테마에서 레이아웃과 기본 진입을 확인한다. 실제 후원 결제·환불 거래나 실사용자 이용 효과를 검증한 것으로 표현하지 않는다.
